# v1.0.0 — 2026-11-01

First public release of Ultraviolette Navigator — a landscape Android cluster UI inspired by the UV X47 / F77 speedometer.

## Highlights

- Live GPS speed, lean angle, battery, and ambient weather on the cluster
- Brand themes: Ultraviolette default plus a full KTM cluster / control-center look
- Control center with animated tiles, bike name, ride modes, and trip history
- Riding smoothness (EFF) and speed discipline (SPD) metrics on the mode bar
- Settings for theme, bike name, and related cluster preferences

## Changes

- Cluster speedometer with odo/trip, status pill, lean/weather, and mode indicators
- Brand theme selection persisted via `BrandThemeStore`, including KTM screens and accents
- KTM cluster body, tachometer, control center, trips screen, and motion kit
- Persistent trip drafts / history (`TripStore`) and trips history UI
- Bike name editing from settings / identity tile
- Staggered tile entry animations across control center, settings, and trips
- Ambient-light-aware theming and GPS availability handling
- Agent harness scripts for deploy, design-facts probe, and smoke checks

## Install

1. Download `ultraviolette-navigator-1.0.0.apk` from this GitHub release.
2. Allow install from the browser/file manager if prompted.
3. Open the APK and install.

Package: `com.ultraviolette.navigator`  
Min Android: 8.0 (API 26) · Landscape recommended
