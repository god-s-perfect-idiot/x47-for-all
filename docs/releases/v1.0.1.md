# v1.0.1 — 2026-11-02

## Highlights
- Fix launch crash on Android 12+ devices that reject fastest sensor sampling without `HIGH_SAMPLING_RATE_SENSORS`

## Changes
- Register motion sensors at `SENSOR_DELAY_GAME` instead of `SENSOR_DELAY_FASTEST` in `SpeedRepository`
- Catch `SecurityException` on sensor registration so GNSS/network speed still works if sensors are blocked

## Install
1. Download `ultraviolette-navigator-1.0.1.apk` from this GitHub release.
2. Allow install from the browser/file manager if prompted.
3. Open the APK and install.

Package: `com.ultraviolette.navigator`
